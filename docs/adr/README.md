# Architecture Decision Records

This directory holds ADRs for the `adlc-engineer` project itself — the same
format the ADLC Engineer tool produces for the repositories it analyzes,
applied to its own engineering decisions.

Format: context → decision drivers → options considered → decision →
consequences. A decision is recorded when it's made, not retroactively
justified, and superseded (not edited in place) when it changes.
